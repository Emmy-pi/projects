# Changelog

## 0.1.0 (2026-11-19)

First public release.

- Data preparation: duplicate removal, likely-duplicate donors set aside for merging, day/month date correction, ambiguous date flagging, negative value correction, and a record-level issues file.
- Donor segmentation with automatically named segments.
- Likelihood-of-giving model, evaluated on held-out donors against a recency rule of thumb.
- Transparent cause affinity score for a scholarship fund for students who have experienced foster care, with a check against past fund gifts.
- Ranked outreach list with four tiers, recommended actions, and renewal flags.
- Plain-language run report.
- Synthetic sample data generator and an example run.
