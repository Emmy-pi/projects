# Privacy and responsible use

## Data stays with you

The toolkit runs on your own computer or server. It does not send data anywhere, and it has no connection to any outside service. Keep input files and results in the same protected locations you use for other donor records, and delete working copies when you are done.

## Donor data, not student data

This version processes donor records only. It does not need, and should not be given, any information about students. Foster care status is sensitive, and nothing in this toolkit asks for it.

Future outcome tracking features will run inside each institution's own systems, under that institution's student privacy rules (including FERPA), so that student records never leave the institution.

## Minimum necessary data

The outreach list identifies donors only by `donor_id`. Email addresses are used only to detect duplicates and are not written to any output. Remove any columns your export includes that the toolkit does not use.

## Fairness

The model and the affinity score use giving and engagement behavior only. Do not add race, ethnicity, religion, age, gender, disability, or other protected characteristics as inputs, and do not use the outputs to exclude anyone from being asked to give. Every donor still appears on the list; the tiers only decide how much staff time each contact receives.

## Check before you rely on it

A model is only as good as the data behind it. Review the data quality report, confirm that the model beats the rule of thumb on your data, and compare results against a small group handled the usual way before changing how you work.
